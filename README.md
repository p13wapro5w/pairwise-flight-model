# pairwise-flight-model

飞机拉升到一定角度后机头突然下坠，升力曲线在失速迎角之后仍按线性外推，没有进入失速平台；方向舵与副翼的力矩按速度平方算，但低速时没有增加舵效补偿，落地滑跑转不动；侧风只作用于机身中心，机翼产生的滚转力矩没算，飞机自己往一边偏；地面效应按高度线性衰减，离地十米仍有 30% 额外升力；自动驾驶的俯仰积分器在配平变化后饱和，切回手动时杆位突然跳；燃油消耗按固定流率，爬升时发动机功率变化没影响；网络同步只发位置与姿态，空速与迎角在客户端各自积分，长时间飞行后两边失速点不同；相机跟随用固定偏移，急盘旋时地平线倾斜方向反了；起落架接地判定只看垂直速度，侧向滑移超过限制仍然算正常着陆；风切变进入时没有预警，升力瞬间掉落后才触发失速警告。gameplay/flight_model.py 是核心，tests/test_flight_model.py 15个红。要修的是：失速后升力平台；低速舵效补偿；侧风滚转力矩；地面效应指数衰减；积分器抗饱和；油耗随功率；同步空速迎角；相机随姿态；接地含侧滑；风切变预警。

## 运行

```bash
python -m pytest tests -q
```
